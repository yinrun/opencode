# Patch 01 — HERsqrt close-out

## Hypothesis
Build 已完成 (HERsqrt.cpp / HERsqrtInterface.cpp / model_hersqrt.cpp / 三目标 .so / device_configs)，
input + ref 已生成。设备工作区残留 rsqrt 的 .so 和 in.raw + 上次失败 log (Context Creation failure)。
按 L1/L4 经验，原失败是 runner 默认命令缺 `:CPU` op_package 注册和 `--config_file`。
直接手动跑完整命令应当 pass。

注意 spec 写 `[1,1,128,1]` 但 build 里实际用 `[1,1,128,128]`（model_hersqrt.cpp dims_in 和
in.raw=32768 bytes=16384 fp16 都验证）。本次按 build 实际 shape 跑。

## Steps
1. 按 L4 手动跑 qnn-net-run，加 `:CPU,:HTP` 双注册 + `--config_file net_run_config.json`：
   ```
   qnn-net-run --backend libQnnHtp.so --model libQnnHERsqrtModel.so \
     --input_list input_list.txt --output_dir output \
     --op_packages libQnnHtpRsqrt.so:HERsqrtPackageInterfaceProvider:CPU,htp/libQnnHtpRsqrt.so:HERsqrtPackageInterfaceProvider:HTP \
     --use_native_input_files --use_native_output_files \
     --config_file net_run_config.json
   ```
2. adb pull /data/local/tmp/qnn_op_test/output/Result_0/output_native.raw
3. tensor-compare_compare_pass

## Result
- cosine_similarity = 1.0
- max_abs_error = 0.0
- relative_error = 0.0
- shape = [1,1,128,128]，16384 fp16 元素
- bit-exact 与 numpy ref 完全一致
- input fp16 ~ N(0,1)，可能含负数 → rsqrt(负)=NaN；device 与 ref NaN pattern 一致，cosine 排除 NaN 后判定通过

## Decision
Mark `rsqrt` 为 `completed`，1 iteration（recovery，无新 patch 需要）。

## Lesson
重复印证 L1+L4：runner 默认命令对所有 custom op 都缺 :CPU 注册和 --config_file，每个 op 都要走 L4 workaround。
没有新 lesson 要追加。
