# Patch 01 — HEGELU close-out

## Approach
GELU 用 tanh 近似形式：
```
y = 0.5 * x * (1 + tanh(sqrt(2/π) * (x + 0.044715 * x³)))
```
Kernel 全程 fp32 算，最后单次 fp16 round。

## Result
- cosine = 0.9999999999996103
- max_abs_err = 6.10e-5 (≈ 0.5 fp16 ULP)
- relative_error = 1.49e-6
- shape = [1,1,128,4864] fp16，622592 元素
- 1 iteration

## Lesson
预期符合 L11 推论 — 复合表达式 op (含 tanh + 多 fp32 mul) 累积误差 0.5–2 fp16 ULP，
不会突破 1e-3 阈值。
