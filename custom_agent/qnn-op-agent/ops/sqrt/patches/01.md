# Patch 01 — HESqrt close-out

## Hypothesis
基础 unary template (silu / rsqrt 模板) 直接克隆。Kernel 单行 `out = sqrtf(xv)`。
存量产物：src/、Makefile、device_configs 已就绪；缺 device output。

## Pitfalls hit
1. **L1 重发**: `qnn-runner_build_single_op_model` overwrite model_src 用了带 `model.finalize()` + `DO_GRAPH_NODE_VALIDATIONS 1` 的 template → composeGraphs Segfault.
   Fix: 手写 model_src 用 `getGraphInfoFromModels()`，再用 NDK clang++ 直接 link，不再调 `build_single_op_model`。
2. **多设备 adb**: 工作站接了 2 台 device，qnn-adb MCP server 报 "more than one device/emulator"。
   Workaround: `export ANDROID_SERIAL=204cbd30 && adb ...` 直接调用。

## Result
- cosine = 0.9999999999999962
- max_abs_err = 0.0 (bit-exact)
- shape = [1,1,128,128] fp16
- 2 iterations (iter1: 错误 model template → segfault; iter2: 手动 link 后 pass)
