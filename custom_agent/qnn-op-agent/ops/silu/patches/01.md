# Patch 01 — silu identity diagnostic loop

## Date
2026-05-28

## Hypothesis
Custom op-package kernel not actually executing on HTP backend at runtime.

## Test sequence
1. **Identity kernel** `out = in` with `Tensor` template variant → cosine(out,in)=0.78 (33.7% match), even lanes 100% wrong
2. **Identity kernel** with `PlainFloat16Tensor` only (mirror canonical ReluFp16.cpp) → bit-identical bad output (cosine 0.78)
3. **Smoking gun**: `SiLUValidateOpConfig` returns `QNN_OP_PACKAGE_ERROR_VALIDATION_FAILURE` unconditionally → graph still composes successfully

## Conclusion
Our op-package is LOADED (no dlopen error, no init failure) but never CONSULTED during graph compose:
- ARM-side validateOpConfig is bypassed
- Hexagon-side siluImpl is bypassed
- Output values `{-2, 0, 2, ±0.0078125}` come from HTP's internal fallback for unrecognized op names

## Likely root cause
`QnnModel.hpp` runtime compose path (`model.addNode("HESiLUPackage", "HESiLU", ...)`) does NOT route to op-packages loaded via `qnn-net-run --op_packages` for HTP backend. The standard pattern for custom ops on HTP is:

1. **Offline pre-compile** the graph with `qnn-context-binary-generator`, which serializes the op-package symbol references into the cached context binary
2. Run the cached binary at inference time via `qnn-net-run --retrieve_context`

The `--op_packages` flag at qnn-net-run only registers packages but the runtime QnnModel compose path does not use that registry to resolve op symbols on HTP.

## Result
FAILED — fundamental infra blocker

## Evidence files
- `ops/silu/outputs/device.raw`: identity test output (cosine 0.78 vs input)
- `ops/silu/build/src/SiLU.cpp`: identity-only kernel
- `ops/silu/build/src/SiLUInterface.cpp`: validateOpConfig=fail (smoking gun)

## Next strategy (if resumed)
Switch from runtime QnnModel compose to offline context-binary path:
1. Use `qnn-context-binary-generator --backend libQnnHtp.so --model libQnnSiLUModel.so --op_packages ... --binary_file <name>`
2. Push the cached binary + op-packages
3. Run `qnn-net-run --retrieve_context <binary>` (no --model, no --op_packages flag at runtime)
4. Confirm identity kernel produces cosine=1.0
5. Replace identity with SiLU math
6. Replace scalar loop with HVX intrinsics for performance
