# Patch 01 — HERound iter 1 (FAIL)

Kernel: `out = roundf(xv)` (C99 round-half-away-from-zero).
Result: cosine=0.9997986, max_abs=1.0 — FAIL.

Root cause: spec specifies "banker's rounding" (round half to even) to match numpy `np.round`, but C99 `roundf()` is round-half-away-from-zero. On values like 0.5, numpy outputs 0 (even) while `roundf` outputs 1, giving max_abs=1.0.

Fix in iter 2.
